## Inputs

|  |  |
| :--- | :--- |
| <b>SDF</b> *Float* | The input SDF shape. |
| <b>Thickness</b> *Float* | The thickness of the shell, applied both inwards and outwards.<br>The shell is rounded when thickness is increased.<br><br><i>Default: 0.02</i> |
