# Intersection surface

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![Intersection surface icon](./3d_sdf_op_intersection_surface.png "Intersection surface")

</td>
<td width="100.00%" style="border: 0;" valign="top">

## Description

Returns the surface of the portion of a base SDF shape that is intersected by another SDF shape, with adjustable thickness.

</td>
</tr>
</table>

<a name='inputs'></a>
## Inputs

|  |  |
| :--- | :--- |
| <b>Base SDF</b> *Float* | The SDF shape that the resulting surface is based on. |
| <b>Intersecting SDF</b> *Float* | The SDF shape intersecting the base SDF shape. |
| <b>Thickness</b> *Float* | The thickness of the resulting surface.<br><br><i>Default: 0.02</i> |
