# Set material ID

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![Set material ID icon](set-id.png "Set material ID")

<b>In:</b> 3D Function &gt; Material

</td>
<td width="100.00%" style="border: 0;" valign="top">

## Description

Set the material ID of an SDF scene. 

This value can then be retrieved for all splattered SDF shapes in the *Splatter UVW* output of the [Shape splatter v2](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/shape-splatter-v2/shape-splatter-v2.md).

</td>
</tr>
</table>

## Inputs

|                          |                        |
|--------------------------|------------------------|
| <b>SDF scene</b> *Float* | The input SDF scene.   |
| <b>ID</b> *Integer*      | The integer ID to set. |
