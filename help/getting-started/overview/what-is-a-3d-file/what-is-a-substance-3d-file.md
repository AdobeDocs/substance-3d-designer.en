# What is a Substance 3D file?

A Substance 3D file (`*.sbs`), also known as a **package**, is a container for resources such as Substance graphs, which are dynamic generators of textures that can be exported to be used in many applications.

Substance graphs are dynamic because contrary to a classic bitmap file, the creator of a Substance graph can choose to **expose parameters** in order to provide controls over the results generated by the graph.

For example, it is possible to change on-the-fly the amount of dust on an object, the color of a soccer team jersey, or the pattern of a cut stone floor. Your imagination is virtually the only limit.

A package can be *published* to a compiled, self-contained **Substance 3D archive file** (`*.sbsar`) so that the graph it contains can then be used in external applications for which a [Substance integration](https://www.adobe.com/products/substance3d/plugins.html) exists.

Substance graphs can produce textures that are **100% procedural**, resulting in very light package file sizes.
