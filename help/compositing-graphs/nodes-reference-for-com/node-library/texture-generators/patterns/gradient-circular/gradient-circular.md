# Gradient Circular

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

<b>In:</b> Texture Generators &gt; Patterns

</td>
<td width="100.00%" style="border: 0;" valign="top">

## Description

Creates a grayscale gradient transition defined by two custom points in a circular fashion. The transition is not from a to b, but rather as a revolution around the first point, starting and ending at the second point. Keep in mind results will never tile.

</td>
</tr>

<a name="parameters"></a>

## Parameters

|  |  |
|:---|:---|
| <b>Point 1</b> | First point to revolve the gradient around, does not have to be centered |
| <b>Point 2</b> | Second point for gradient to start and end at. |
| <b>Non Square Expansion</b> <i>False/True</i> | Enable compensation of squash and stretch with non-square ratios. |
