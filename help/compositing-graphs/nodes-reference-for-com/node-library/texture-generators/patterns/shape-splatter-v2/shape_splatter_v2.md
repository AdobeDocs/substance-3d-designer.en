## Description

Scatters shapes on a background height surface with advanced capabilities for scattering in a virtual <b>3D space</b>, with controls for position, rotation, scaling and randomness.<br><br>The node offers basic primitive 3D shapes and supports custom ones provided either as a <b>pattern image</b>, an <b>atlas</b>, or as a <b>signed distance field (SDF)</b> function for complex custom 3D shapes.<br><br>Several <b>methods of distributing shapes</b> are available, including authoring a custom function for complete control.<br><br>Shapes can be pulled towards specific areas using a custom <b>density map</b>.<br><br><i>Note:</i> This node is not meant to be used with the CPU versions of the Substance engine, I.e. SSE2 (Windows, Linux) and NEON (macOS).
