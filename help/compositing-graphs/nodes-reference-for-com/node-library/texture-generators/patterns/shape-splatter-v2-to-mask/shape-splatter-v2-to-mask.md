# Shape splatter v2 to mask

<td width="33.33%" style="border: 0;" valign="top">

</td>
<td width="100.00%" style="border: 0;" valign="top">

## Description

Computes a mask out of a selection of shapes generated by the [Shape splatter v2](../shape-splatter-v2/shape-splatter-v2.md) node .<br><br>Available options include random selection as well as selecting ranges of shapes by unique identifier and/or material ID/pattern ID*.<br><br>Shapes are pre-masked by the [Shape splatter v2](../shape-splatter-v2/shape-splatter-v2.md) node from their <i>height blend</i> with the background height.<br>Both the background and the unselected shapes are pure black. (I.e a value of 0)<br><br><b>*:</b> One of the values retrieved from the Shape splatter UVW input is either the material ID or pattern ID, depending on the <b>Shape type</b> used in the Shape splatter v2 node:<br>- <i>SDF/primitive</i>: Material ID<br>- <i>Pattern input/Grid atlas:</i> Pattern ID, I.e. the index of the pattern in the list/atlas.

<a name="inputs"></a>

## Inputs

|                             |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
|:----------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b>Splatter UVW</b> *Color* | <b>R</b> - U component of the shapes' UVs.<br><b>G</b> - V component of the shapes' UVs.<br><b>B</b> - The shapes' height. (W)<br><b>A</b> - Packed data:<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;- <i>Integer part:</i> The shapes' unique identifier. (ID)<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;- <i>Fractional part:</i> Depends on the <b>Shape type</b>: Material ID if SDF/primitive, pattern ID* if pattern input/grid atlas.<br><br><b>*:</b> The pattern ID is the index of the shape in the list/atlas. |

<a name="outputs"></a>

## Outputs

|               |                                           |
|:--------------|:------------------------------------------|
| <b>Output</b> | The computed mask of the selected shapes. |

<a name="parameters"></a>

## Parameters

|                                                         |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|:--------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b>Output</b> *Integer*                                 | The values used for the selected shapes in the output mask.<br><br>- <b>Binary mask:</b> Selected shapes all use a value of 1.<br>- <b>Shape ID (integer):</b> Selected shapes use their unique identifier. (ID)<br>- <b>Material ID (integer):</b> Selected shapes use their material ID.<br>- <b>Shape ID (normalized):</b> Selected shapes use their unique identifier (ID) mapped to the [0, 1] range from the lowest selected ID to the highest.<br>- <b>Material ID (normalized):</b> Selected shapes use their material ID mapped to the [0, 1] range from the lowest selected material ID to the highest. |
| <b>Shape ID start range</b> *Integer*                   | The shape unique identifier (ID) used as the start of the selection range. (Included)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| <b>Shape ID end range</b> *Integer*                     | The shape unique identifier (ID) used as the end of the selection range. (Included)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| <b>Shape ID offset</b> *Integer*                        | Offsets the shapes' unique identifiers by the specified value, in the context of the selection range.<br><br>This makes it easy to offset the current selection by the specified value without having to adjust the start and end bounds manually.                                                                                                                                                                                                                                                                                                                                                                |
| <b>Material / pattern id mask combination</b> *Integer* | Specified the logical operator used to combine the selection by unique identifier (ID) with the selection by material ID/pattern ID.<br><br>- <b>None:</b> Ignore the material ID/pattern ID entirely for the selection.<br>- <b>AND:</b> Selected shapes have to be included in both the ID and material ID/pattern ID ranges. (Includes less shapes)<br>- <b>OR:</b> Selected shapes have to be included in either the ID or material ID/pattern ID ranges. (Includes more shapes)                                                                                                                              |
| <b>Material / pattern ID start range</b> *Integer*      | The material ID or pattern ID* used as the start of the selection range. (Included)<br><br><b>*:</b> See node description for details.                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| <b>Material / pattern ID end range</b> *Integer*        | The material ID or pattern ID* used as the end of the selection range. (Included)<br><br><b>*:</b> See node description for details.                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| <b>Shape random mask</b> *Float*                        | A factor for the random masking of shapes, where 1 means all shapes are masked.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
