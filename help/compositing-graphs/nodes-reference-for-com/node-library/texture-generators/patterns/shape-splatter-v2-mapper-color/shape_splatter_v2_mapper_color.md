# Shape splatter v2 mapper color

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![Shape splatter v2 mapper color icon](shape_splatter_v2_mapper_color.png "Shape splatter v2 mapper color")

<b>In:</b> Generator &gt; Pattern

</td>
<td width="100.00%" style="border: 0;" valign="top">

## Description

Maps color images on shapes generated and scattered using the [Shape splatter v2](../shape-splatter-v2/shape_splatter_v2.md) node , using the additional data provided by the node.<br><br>Images are provided as separate pattern inputs or packed into a grid atlas, and can be applied to the shapes using UV mapping, triplanar projection or custom mapping.<br><br>Shapes can be tinted and their colors adjusted uniformly or randomly per shape.

See also [Shape splatter v2 mapper grayscale](../shape-splatter-v2-mapper-grayscale/shape_splatter_v2_mapper_grayscale.md).

</td>
</tr>
</table>

>[!TIP]
>
> This node requires input data generated by the [Shape splatter v2](../shape-splatter-v2/shape_splatter_v2.md) node.
> 
> Other nodes in the Shape splatter v2 family:
> * [Shape splatter v2 to mask](../shape-splatter-v2-to-mask/shape_splatter_v2_to_mask.md)

>[!INFO]
>
> The [Grid atlas color](../grid_atlas_color/grid_atlas_color.md) nodes let you pack images into an atlas of custom size, up to 16 patterns in 4*4 cells.
