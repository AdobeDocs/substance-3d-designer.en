## Parameters

|  |  |
|:---|:---|
| <b>Rotation</b> <i>0.0 - 1.0</i> | Rotates effect internal calculations. This can change the visual look of the noise quite a bit: the further away from 1, the less pixel-scaled the effect is and the more visible "waves" are introduced. |
