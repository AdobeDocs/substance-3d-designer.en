## Description

The **Grunge Rough Dirty** node generates a grunge map akin to a rough dirty surface with fine parallel scratches.

</td>

<a name="parameters"></a>

## Parameters

|  |  |
|:---|:---|
| <b>Balance</b> <i>Float</i> | Adjusts the balance between dark and bright values. |
| <b>Contrast</b> <i>Float</i> | Adjusts the contrast of the image. |
| <b>Invert</b> <i>Boolean</i> | Inverts the output of the image, using a `1-x` operation. |
| <b>Non Square Expansion</b> <i>Boolean</i> | Enables compensation of squash and stretch with non-square ratios. |
| <b>Advanced</b> |  |
| <b>Main Grunge Intensity</b> <i>Float</i> | Adjusts the intensity of the main grunge texture used to break up the surface. |
| <b>Invert Scratches</b> <i>Boolean</i> | Inverts the luminance of the scratches on the surface. |
| <b>Scratches Intensity</b> <i>Float</i> | Adjusts the intensity of the scratches on the surface. |
| <b>Grain Intensity</b> <i>Float</i> | Adjusts the intensity of the global grain effect. |
