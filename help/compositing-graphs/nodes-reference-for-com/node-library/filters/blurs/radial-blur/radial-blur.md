<a name="parameters"></a>

## Parameters

|  |  |
|:---|:---|
| <b>Samples</b> <i>1 - 128</i> | Set the quality of the blur effect. |
| <b>Angle</b> <i>0.0 - 0.5</i> | Set the amount of "spin" of the effect. |
| <b>Center Position</b> | Set the centerpoint of the effect. |
