<a name="parameters"></a>

## Parameters

|  |  |
|:---|:---|
| <b>Min</b> <i>0.0 - 1.0</i> | Lower clamp limit. |
| <b>Max</b> <i>0.0 - 1.0</i> | Upper clamp limit. |
| <b>Apply to Alpha</b> <i>False/True</i> (Color version only) | Choose whether clamping is applied to the alpha as well. |
