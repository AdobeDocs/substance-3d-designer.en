## Description

Separates a Heightmap's frequencies into two separate maps: one with large-scale differences and one with small-scale differences.

## Parameters

|  |  |
|:---|:---|
| <b>Relief</b> <i>0.0 - 32.0</i> | Controls the Displacement output's detail size. |
