## Parameters

|  |  |
|:---|:---|
| <b>Range Min</b> <i>-2.0 - 0.0</i> | Minimum range to start highlighting. |
| <b>Range Max</b> <i>1.0 - 3.0</i> | Maximum range to highlight up to. |
