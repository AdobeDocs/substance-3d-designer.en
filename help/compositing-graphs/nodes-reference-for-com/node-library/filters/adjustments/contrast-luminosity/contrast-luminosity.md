<a name="parameters"></a>

## Parameters

|  |  |
|:---|:---|
| <b>Contrast</b> <i>-1.0 - 1.0</i> | Adjusts the contrast of the result. |
| <b>Luminosity</b> <i>-1.0 - 1.0</i> | Adjusts the luminosity (brightness) of the result. |
