# 3D viewer

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![3D viewer icon](./3d-viewer.resources/3d-viewer.png "3D viewer")

<b>In:</b> Filter &gt; Effect

</td>
<td width="100.00%" style="border: 0;" valign="top">

## Description

Computes a 3D render for a specified SDF or intersection scene defined by a function graph, with a custom camera and environment light.<br><br>This node is useful for authoring and visualizing [SDF functions](../../../../../../function-graphs/nodes-reference-for-fun/function-node-library/function-node-library.md#sdf-functions) to be used in the [Shape splatter v2](../../../texture-generators/patterns/shape-splatter-v2/shape-splatter-v2.md) node .<br><br>Helpers are available to visualize key attributes of shapes in space.<br><br>For advanced users, custom functions can be authored to set up the camera and/or the 3D render per pixel.

</td>
</tr>
</table>

>[!INFO]
> 
> To learn more about concepts and workflows involving SDF functions, go to the dedicated page: [Working with SDF functions](../../../../../../function-graphs/nodes-reference-for-fun/function-node-library/function-nodes-sdf-functions/working-with-sdf-functions.md)

<a name="inputs"></a>

## Inputs

|                            |                                                                                                                                                                                                                                                                                                                                                                                           |
|:---------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b>Environment</b> *Color* | The image that should be projected onto the infinite sphere used as the scene's environment, and used for the environment lighting.<br><br>The projection is <i>equirectangular</i>, the same used by Designer's default environment maps available in the <b>3D View > HDRI environments</b> category of the Library.<br><br><i>Tip:</i> Use an HDR image (32-bit) for precise lighting. |
| <b>Input 1</b> *Color*     | An image that may be sampled in the <b>Custom output</b> function graph when the <b>Output</b> parameter is set to 'Custom'.<br><br>Use a [Sample color](../../../../../../function-graphs/nodes-reference-for-fun/atomic-function-nodes/sampler-nodes/sampler-nodes.md) node set to 'Image input 0' to sample from this image.                                                           |
| <b>Input 2</b> *Color*     | An image that may be sampled in the <b>Custom output</b> function graph when the <b>Output</b> parameter is set to 'Custom'.<br><br>Use a [Sample color](../../../../../../function-graphs/nodes-reference-for-fun/atomic-function-nodes/sampler-nodes/sampler-nodes.md) node set to 'Image input 1' to sample from this image.                                                           |

<a name="outputs"></a>

## Outputs

|               |                                                                                                                                                                                                                                    |
|:--------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b>Output</b> | The rendered scene, using the AOV selected in the <b>Output</b> parameter.<br><br><i>Note:</i> For accurate readings in some AOVs, make sure the 2D View uses a linear color space, and the node uses an HDR 32-bit output format. |

<a name="parameters"></a>

## Parameters

|                                               |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
|:----------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b>Scene type</b> *Integer*                   | The type of function used to describe the surfaces and shapes to be rendered:<br>- <b>SDF:</b> Use a signed distance field (SDF) function, which can describe complex shapes.<br>- <b>Intersection:</b> Use intersection functions, which are faster when only simple primitive shapes are needed.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| <b>SDF scene</b> *Float*                      | The signed distance field (SDF) function describing the surfaces and shapes in the scene.<br><br>Use the nodes in the [SDF functions](../../../../../../function-graphs/nodes-reference-for-fun/function-node-library/function-node-library.md#sdf-functions) category of the Library to author the function.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| <b>Intersect scene</b> *Float*                | The intersection function describing the surfaces and shapes in the scene.<br><br>Intersection functions for simple primitives and operators are available in the <b>3d_intersection</b> folders of the <b>3d_functions.sbs</b> Library package.<br><br><i>Tip:</i> You can access the package by dropping any SDF node from the Library into the Explorer.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| <b>Output</b> *Integer*                       | The type of 3D render that should be output by the node, commonly referred to as AOVs (Arbitrary output variables).<br><br>Available AOVs are:<br>- <b>Beauty:</b> The final result of the 3D render, with art-directed colors and effects.<br>- <b>Normal WS:</b> The world space normals of the shapes in the scene.<br>- <b>Normal TS:</b> The tangent space normals of the shapes in the scene.<br>- <b>Position:</b> The world space position of the surfaces of the shapes in the scene.<br>- <b>Distance:</b> The raw distance from the camera to the shapes in the scene<br>- <b>Depth:</b> The signed distance of the shapes from the camera target plane, where the plane always faces the camera.<br>- <b>Color:</b> The shapes' base color (Use the 'Set color' node to assign colors to shapes in the scene function)<br>- <b>Material ID:</b> The material IDs applied to the shape surfaces (Use the 'Set material ID' node to assign material IDs to shapes in the scene function)<br>- <b>Sphere tracing steps:</b> A visualization of the amount of steps required for defining the surface of a shape. Brighter values mean more steps were required.<br>- <b>Custom:</b> Author a custom function to compute the color of the render per pixel.<br><br><i>Note:</i> For accurate readings in some AOVs, make sure the 2D View uses a linear color space, and the node uses an HDR 32-bit output format.                                                                                                                                                                                                        |
| <b>Custom output</b> *Float4*                 | The function graph defining the per-pixel RGBA colors of the rendered scene, as a Float4 value.<br><br>Available variables:<br>- <code>scene.position</code> (Float3) The world space position of the scene's surfaces.<br>- <code>scene.normal</code> (Float3) The world space normals of the scene's surfaces.<br>- <code>scene.hit</code> (Boolean) Returns 'True' when a surface is hit by a camera ray.<br>- <code>view.origin</code> (Float3) The per-pixel world space position of the camera view.<br>- <code>view.direction</code> (Float3) The per-pixel forward vector of the camera view, according to the projection mode. (E.g. perspective or orthographic)<br>- <code>material.color</code> (Float3) The base color of the scene's surfaces.<br>- <code>material.metalness</code> (Float) The metalness of the scene's surfaces.<br>- <code>material.roughness</code> (Float) The roughness of the scene's surfaces.<br>- <code>material.id</code> (Integer) The material IDs of the scene's surfaces.<br><br>The node's image inputs can be sampled by selecting the following [Sample color](../../../../../../function-graphs/nodes-reference-for-fun/atomic-function-nodes/sampler-nodes/sampler-nodes.md) node slots:<br>- <b>Image input 0</b> samples Input 1.<br>- <b>Image input 1</b> samples Input 2. |
| <b>Environment rotation</b> *Float*           | The rotation of the <b>Environment</b>, in number of turns.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| <b>Background mode</b> *Integer*              | Specifies the source of the scene's background, drawn where no shape surfaces are visible.<br><br>- <b>Color:</b> The flat 'Background color'.<br>- <b>Environment:</b> The image provided to the 'Environment' input, applied to an infinite sphere using equirectangular projection.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| <b>Background color</b> *Float4*              | The flat color used as the scene's background.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| <b>IBL samples</b> *Integer*                  | The amount of light samples performed per camera sample.<br><br>A higher value results in smoother, more accurate lighting at the cost of performance.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| <b>Camera samples</b> *Integer*               | The amount of camera samples performed per pixel.<br><br>This parameter affects the quality of the anti-aliasing and the depth of field effect.<br><br>A higher value results in a clearer, less noisy image at the cost of performance.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| <b>Ray marching steps</b> *Integer*           | The amount of steps performed in the sphere tracing process, the ray marching technique used to detect and draw the surfaces of the shapes.<br><br>A higher value results in accurate, consistent surfaces (especially for complex shapes), at the cost of performance.<br><br><i>Tip:</i> Set the <b>Output</b> parameter to the 'Sphere tracing steps' AOV to visualize the areas of the shapes that require more steps. These areas will be impacted first by reducing the amount of steps.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| <b>Secondary ray marching steps</b> *Integer* | The amount of steps performed in the sphere tracing process to compute the diffusion and specular occlusion in order to draw cast shadows.<br><br>A higher value results in more accurate shadows at the cost of performance.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| <b>Camera mode</b> *Integer*                  | The method of projecting the scene onto the render image:<br><br>- <b>Perspective:</b> This projection conveys depth and enables lens effects such as depth of field.<br>- <b>Orthographic:</b> This projection flattens the scene, nullifying depth.<br>- <b>Custom function:</b> Author a function graph to set up a custom camera.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| <b>Camera function</b> *Float3*               | The function graph defining the camera's transform. This may be used for setting up a custom camera.<br><br>The function should <b>set</b> these variables:<br>- <code>view.origin</code> (Float3) The per-pixel world space position of the camera view.<br>- <code>view.direction</code> (Float3) The per-pixel forward vector of the camera view, according to the projection mode. (E.g. perspective or orthographic)<br><br>The following variables are available to <b>get</b>:<br>- <code>camera.origin</code> (Float3) The world space position of the camera. (camera.direction * camera_distance + camera.target)<br>- <code>camera.direction</code> (Float3) The world space direction of the camera, I.e. the camera's Y-forward vector.<br>- <code>camera.right</code> (Float3) The camera's X-right vector.<br>- <code>camera.up</code> (Float3) The camera's Z-up vector.<br>- <code>camera.target</code> (Float3) The world space position of the camera target.                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| <b>UV position</b> *Float2*                   | The position in 2D image space used to infer the camera position and direction orbiting the <b>Target position</b>.<br><br><i>Tip:</i> This parameter can be adjusted intuitively by using the <i>position gizmo</i> available in the 2D View when the node is selected.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| <b>FOV</b> *Float*                            | The orthographic camera's field of view (FOV), which impacts the zoom factor.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| <b>Focal length</b> *Float*                   | The camera's focal length, which impacts the zoom factor and depth of field effect.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| <b>Distance from target</b> *Float*           | The distance that the camera should rest from the <b>Target position</b>.<br><br>Adjusting this moves the camera along the camera-to-target direction.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| <b>Target position</b> *Float3*               | The position of the camera target, towards which the camera is always oriented.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| <b>Tonemapper</b> *Integer*                   | The tonemapping algorithm that should be applied to the scene render.<br><br>- <b>None (Raw)<br>- <b>sRGB</b><br>- <b>AgX</b><br>- <b>ACES</b>                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| <b>Enable depth of field</b> *Boolean*        | Simulates the 'depth of field' camera lens effect for the perspective camera.<br><br>Use the <b>F number</b> and <b>Focus distance</b> parameters to adjust the aperture and focal point of the effect respectively.<br><br>The result is also impacted bt the <b>Focal length</b>.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| <b>F-number</b> *Float*                       | The camera's <i>aperture</i>.<br><br>A lower value results in a shorter <i>depth of field</i>, I.e. a shorter distance range for objects being sharp and a stronger blurring effect as the distance from that range increases.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| <b>Focus distance</b> *Float*                 | Sets the distance of the focal point as a distance from the camera along along its forward vector.<br><br>Surfaces within range of that distance will appear sharp, that range — the <i>depth of field </i> — is defined by the <b>F-number</b>.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| <b>Exposure (EV)</b> *Float*                  | The amount of light reaching the camera sensor, I.e. the intensity of the lighting in the render.<br><br>A lower value results in a darker rendered scene.<br><br>The 'Exposure Value' (EV) specifically refers to how much light the camera sensor is <i>exposed</i> to.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| <b>Base color</b> *Float3*                    | The default base color for surfaces where that color is not defined by its SDF or intersection function.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| <b>Roughness</b> *Float*                      | The default roughness value for surfaces where that value is not defined by its SDF or intersection function.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| <b>Metalness</b> *Float*                      | The default metalness value for surfaces where that value is not defined by its SDF or intersection function.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| <b>Helpers opacity</b> *Float*                | The opacity of the 3D helpers, where a lower value results in fainter helpers.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| <b>Bounding frame</b> *Boolean*               | A visualization of a six-sided cage defining the bounds of the entire scene. Should ideally be the smallest possible size which fully includes the scene.<br><br>Use the <b>Bounding frame size</b> parameter to adjust the size of the cage.<br><br>The <b>Colorize out of frame</b> parameter lets you easily visualize the surfaces outside of that cage, which impacts the result of using that scene in the [Shape splatter v2](../../../texture-generators/patterns/shape-splatter-v2/shape-splatter-v2.md) node . (See 'Bounding frame size' tooltip)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| <b>Bounding frame size</b> *Float3*           | Sets the XYZ size of the bounding frame.<br><br>Adjust the frame to your scene, then apply those same values to the <b>SDF bound frame size</b> parameter of the [Shape splatter v2](../../../texture-generators/patterns/shape-splatter-v2/shape-splatter-v2.md) node to ensure all shapes in the scene are correctly included and drawn by that node.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| <b>Colorize out of frame</b> *Boolean*        | Applies a red color to the surfaces outside of the bounding frame.<br><br>This helps check that the scene is fully included in its bounding frame.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| <b>Axis</b> *Boolean*                         | A visualization of the scene's XYZ axes as colored lines starting at the scene's origin.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| <b>Grid</b> *Boolean*                         | A visualization of a grid laid on the XY axes, where the size of one cell in X and Y is one scene unit.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| <b>Transform helpers</b> *Boolean*            | A visualization of the last applied rotation.<br><br>The visualisation includes<br>- <b>An arrow</b> representing the rotation axis direction vector, and colored after the weights of each world space axis.<br>- <b>An arc</b> representing the rotation angle, orthogonal to the arrow matching its color.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| <b>SDF isolines</b> *Boolean*                 | A colored visualization of the signed distance field (SDF) function isolines.<br><br>The isolines are regularly repeating lines representing the <i>distance field</i> of the shape on the XY plane at a given height.<br><br>These are useful for checking the <i>uniformity of the space</i> defined by the SDF function.<br><br>Use the <b>SDF isolines frequency</b> and <b>SDF isolines position</b> parameters to adjust the density and height of the isolines.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| <b>SDF isolines frequency</b> *Float*         | The amount of isoline repetitions within a given distance.<br><br>A higher value results in denser, thinner lines.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| <b>SDF isolines position</b> *Float*          | The world space height of the XY plane used to draw the isolines.<br><br>Use this to check the distance field of the shape at various elevations.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| <b>Min. hit distance</b> *Float*              | Defines the minimum distance that translates into a hit for the SDF ray marching process.<br><br>A low value will increase the number of ray marching steps.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
