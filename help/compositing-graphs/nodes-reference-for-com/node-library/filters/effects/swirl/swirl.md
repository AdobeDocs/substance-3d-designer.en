## Description

This transforms an input image by warping it in a swirling direction. It has additional control for moving the Swirl around to parts of the canvas.

## Parameters

|  |  |
|:---|:---|
| <b>Matrix</b> | Allows you to manually move the Swirl effect around. Can also be modified by interacting with the handles in the 2D preview. |
| <b>Matrix</b> <i>(Transformation Matrix)</i> |  |
| <b>Offset</b> <i>0.0 - 1.0</i> |  |
| <b>Amount</b> <i>-16.0 - 16.0</i> | Strength of the swirling effect. |
